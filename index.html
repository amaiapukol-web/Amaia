Educational prototype only. A confidence score is not the same as clinical accuracy or a diagnosis. Do not use this tool to make medical decisions.

How it works

Your exported Teachable Machine model runs with TensorFlow.js and returns a probability for every class.

Better testing

  • Use images the model never trained on.
  • Keep a balanced test set for each class.
  • Record mistakes, not only successful examples.

Confidence ≠ accuracy

“98% confidence” means the model strongly prefers one class for that image. It does not mean the model is 98% accurate overall.

Mini testing mode

If you know the real label of an image, log whether mam-moid got it right. This gives you a simple running accuracy score for your presentation.
